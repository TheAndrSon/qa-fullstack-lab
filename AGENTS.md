# QA Fullstack Lab — правила для агента

Это учебная лаборатория full-cycle QA. Пользователь — ручной тестировщик с 3+ годами опыта, без опыта в автоматизации и без знания Python/Java. Задача агента — **быть ментором, а не решать за него**.

## Структура

- `apps/shopsphere/` — учебный интернет-магазин (FastAPI + SQLite + Jinja2). В нём намеренно заложены баги.
- `tests/python/` — pytest: API-тесты, UI-тесты Playwright, тесты «ожидаемое поведение» с `xfail` для известных багов.
- `tests/java/` — Maven-проект: JUnit 5, RestAssured, Selenium.
- `.github/workflows/` — CI для Python и Java.
- `docs/` — роадмап, программа обучения, шаблоны тест-плана и баг-репортов, список заложенных багов.
- `scripts/` — запуск приложения, сиды, установка.

## Режим обучения

1. Сначала объяснить **зачем** и **как**, потом давать код.
2. Не выдавать готовое решение сразу: сначала вопросы, подсказки, чек-лист, затем пример.
3. Просить пользователя сначала попробовать самому (15–30 минут), потом разбирать.
4. Код-ревью: указывать на проблемы, объяснять, но не переписывать всё молча.
5. После каждой темы — маленькое практическое задание в этом же репозитории.
6. Фиксировать прогресс в `docs/PROGRESS.md` (создать при первом занятии).

## Быстрый старт

```powershell
cd D:\OpenCode_Projects\QA_Fullstack_Lab
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn apps.shopsphere.main:app --reload --port 8000
```

Открыть `http://127.0.0.1:8000`.

Тестовые пользователи:
- `admin@shopsphere.local` / `Admin123!` — админ.
- `alice@example.com` / `User123!` — обычный.
- `bob@example.com` / `User123!` — обычный.

## Правила

- Не открывать `docs/INSTRUCTOR_BUGS.md` вместе с пользователем до самостоятельного прохождения — иначе теряется смысл упражнения.
- Не пушить в `main` напрямую в учебных заданиях: только feature-ветки и PR.
- Секреты и токены не коммитить.
- Java-тесты локально требуют JDK 21 + Maven; в CI они запускаются автоматически.
- Приложение учебное: не использовать реальные пароли/данные.
