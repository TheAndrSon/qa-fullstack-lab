# Заложенные баги (не открывать до самостоятельного тестирования)

> Это ответы для самопроверки. Сначала пройди чек-лист, оформи баги, потом сверься.

## BUG-01 — Отрицательное количество в корзине

- **Где:** `POST /api/cart`, `POST /cart/update`.
- **Шаги:** войти как alice → добавить товар → в корзине указать `-5` → обновить.
- **Ожидаемо:** количество < 1 отклоняется (400 / сообщение).
- **Фактически:** количество `-5`, итог отрицательный.
- **Severity:** High.

## BUG-02 — Поиск чувствителен к регистру

- **Где:** `GET /api/products?q=...`, главная страница.
- **Шаги:** открыть каталог → ввести `aurora`.
- **Ожидаемо:** находит «Aurora Headphones».
- **Фактически:** пусто; `Aurora` находит.
- **Severity:** Medium.

## BUG-03 — IDOR: чужой заказ

- **Где:** `GET /api/orders/{id}`, `/orders/{id}`.
- **Шаги:** alice оформляет заказ → bob (или аноним) открывает `/api/orders/<id>`.
- **Ожидаемо:** 403/404.
- **Фактически:** 200 и данные чужого заказа, включая email.
- **Severity:** Critical.

## BUG-04 — Дубликат email в другом регистре

- **Где:** `POST /api/register`, `/register`.
- **Шаги:** зарегистрировать `Alice@Example.com` при существующем `alice@example.com`.
- **Ожидаемо:** 409/400.
- **Фактически:** 201, создаётся второй аккаунт.
- **Severity:** High.

## BUG-05 — Корзина не очищается при логауте

- **Где:** `/logout`, `POST /api/logout`.
- **Шаги:** alice добавляет товар → выходит → входит bob.
- **Ожидаемо:** корзина bob пуста.
- **Фактически:** bob видит товар alice.
- **Severity:** High.

## BUG-06 — Админка доступна обычному пользователю

- **Где:** `GET /admin`.
- **Шаги:** войти как alice → открыть `/admin`.
- **Ожидаемо:** 403 / редирект.
- **Фактически:** 200, страница админки.
- **Severity:** High.

## BUG-07 — Остаток не проверяется при checkout

- **Где:** `POST /api/checkout`, `/checkout`.
- **Шаги:** добавить 999 единиц товара с остатком 12 → оформить.
- **Ожидаемо:** 400 «недостаточно товара».
- **Фактически:** 201, заказ создан, остаток не изменился.
- **Severity:** High.

## Как проверять

```powershell
pytest -q tests/python/test_bugs_expected_fail.py
```

Все 7 тестов помечены `xfail(strict=True)`: пока баг есть — CI зелёный. Когда исправишь баг, тест начнёт `XPASS` и упадёт — убери маркер и добавь тест в обычный набор.
